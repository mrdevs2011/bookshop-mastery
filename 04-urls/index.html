4. URLs — yo‘llar xaritasi

Har bir manzil qaysi funksiyaga boradi?

urls.py = telefon kitobi: ism (URL) → raqam (view).
urlpatterns = [
    path('admin/', admin.site.urls),
    path('book-list/', book_list),
    path('add-book/', add_book),
    path('book//', book_page),   # id raqam
    path('login/', login),
    path('logout/', logout),
    path('signup/', mrsign),
    path('error/', TemplateView.as_view(template_name='error.html')),
    path('', index),   # bosh sahifa
]
URLViewVazifa
/indexLogin yoki katalogga yo‘naltir
/login/loginKirish
/signup/mrsignRo‘yxat
/logout/logoutChiqish
/book-list/book_listKatalog
/add-book/add_bookYangi kitob
/book/5/book_pageBitta kitob (id=5)
/error/TemplateViewXato sahifa
= URL dagi raqamni id deb view ga uzatadi.
Masalan /book/12/ → book_page(request, id=12)

Yoddan

urlpatterns ro‘yxatini yoddan yozing (kamida 6 ta path).
