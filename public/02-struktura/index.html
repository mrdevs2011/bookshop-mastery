Har bir papka va faylning vazifasi.

BookShopBomba/
├── manage.py          # Django ni boshqarish (runserver, migrate...)
├── requirements.txt   # kerakli kutubxonalar
├── db.sqlite3         # ma’lumotlar bazasi
├── core/              # loyiha sozlamalari
│   ├── settings.py
│   ├── urls.py        # BARCHA yo‘llar shu yerda
│   └── views.py       # BARCHA mantiq shu yerda
└── main/              # asosiy ilova
    ├── models.py      # jadval (Book, BookView)
    └── templates/     # HTML fayllar
        ├── login.html
        ├── signup.html
        ├── books-list.html
        ├── book.html
        ├── add_book.html
        └── error.html
models.pyBaza jadvallari
urls.pyQaysi URL → qaysi view
views.pyIshchi mantiq
templates/Ko‘rinish (HTML)
4 ta so‘z: Model → URL → View → Template
Eslab qoling:
• Ma’lumot saqlash = models.py
• Yo‘l bog‘lash = urls.py
• Mantiq = views.py
• Ko‘rinish = templates/
