1. Kirish

Django nima? BookShop nima qiladi? Qanday ishlaydi?

Django nima?

Django = veb-sayt qurish uchun tayyor asboblar to‘plami (Python da).
Siz Python da qoidalar yozasiz. Django ularni brauzerga tushunarli qiladi.
Masalan: “/login/ ochilsa — login funksiyasini ishlat”.

BookShop nima qiladi?

  • Ro‘yxatdan o‘tish / kirish / chiqish
  • Kitob qo‘shish (nom, URL, ommaviy/shaxsiy)
  • O‘z katalogingizni ko‘rish
  • Ommaviy kitoblarni ko‘rish
  • Bitta kitob sahifasi + ko‘rishlar soni

Asosiy oqim (yodda saqlang)

1. So‘rov→ 2. URL topiladi→ 3. View ishlaydi
4. Model (baza)→ 5. Template (HTML)→ 6. Javob

Tekshiruv

2) URLdan keyin nima ishlaydi?
3) HTML qayerdan keladi?

Javob: 1) So‘rovni qabul qilib javob beradi. 2) View. 3) Template (render orqali).
